# Мумі-долина — покрокова пригода (робоча назва)

Домашня гра тата й сина (4.5 роки). Ходимо почергово персонажами по мотивах
історій про мумі-тролів. Динаміка як у «Героях 3», тільки набагато простіше:
герой рухається по карті, збирає бонуси, оминає або долає перешкоди, зустрічає події.

**Не розробники.** Тому: чистий HTML + JS, без складання (build), без бібліотек.
Відкрив файл у браузері — і працює.

**Повний опис гри та POC-роадмап** (базовий документ, звідки йде все інше):
`docs/00-opys-gry.md`.

## Як ми будуємо (кроки)

1. **Персонажі** — обрати візуальний стиль. → `design/characters.html`
2. **Світ / карта** — як виглядає долина, з чого складається поле.
3. **Динаміка гри** — скільки кроків за хід, що дають бонуси, як працюють перешкоди.
4. **Доопрацювання дизайну** — на базі скетчів з кроків 1–2.
5. **Прототип** — перша грабельна версія.

Зараз: **POC-етап 0b** — порожній лабіринт, у який уже можна грати
(`index.html`). Генератор карт — `tools/map-generator.html`.

## Структура проєкту

```
index.html  гра — відкривати подвійним кліком
design/     скетчі та вибір стилю — відкривати у браузері
docs/       опис гри, стек, нотатки (див. docs/00-opys-gry.md)
src/        код гри
  core/       рушій: реєстр, карта, ходи, камера, рендер
  characters/ кожен персонаж — окремий файл-модуль
  obstacles/  кожна перешкода — окремий файл-модуль
  bonuses/    кожен бонус — окремий файл-модуль
  tasks/      кожен тип завдання — окремий файл-модуль
  maps/       кожна карта-рівень — окремий файл-модуль
  mapgen/     генератор карт (для «Нова гра» і для tools/)
skin/       скін: усі картинки й звуки гри (плитки, фішки, позначки, музика)
tools/      сторінка генератора карт з прев'ю (розробка)
```

## Принцип модульності

Усе — це дані. Щоб додати персонажа / бонус / перешкоду, дописуємо один
маленький файл + один рядок у маніфесті `index.html`, головний код не чіпаємо.

```js
// src/characters/moomintroll.js
Game.registerCharacter({
  id: 'moomintroll',
  name: 'Мумі-троль',
  move: 5,            // кроків за хід
  image: 'moomintroll',  // id картинки зі скіна
});
```

Такий самий підхід для `bonuses/`, `obstacles/`, `tasks/`, `maps/`.

**Без білд-кроку, без сервера**: `index.html` відкривається подвійним
кліком. Деталі — `docs/02-arhitektura.md`.

## Графіка

Просто, без зайвих деталей, плоскі кольори. Персонажі / бонуси / помічники —
PNG-картинки (генеруємо AI). Обраний стиль з кроку 1 стане еталоном.

Усі картинки лежать в одній теці `skin/` — це **скін**. Ім'я файлу = id
картинки + `.png`, список id — у `skin/skin.js`. Новий стиль = перегенерувати
теку з тими самими іменами; код гри не змінюється. Зараз там тимчасовий
програмний арт і синтезована музика; скрипти, що їх роблять, живуть поза грою
(`~/Projects/maxmap-tilegen/`).
